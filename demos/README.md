# Demo clips

Twenty recordings of a throwaway itcmdr 1.3.2 demo (an admin server, an office server and two client PCs). Each clip is 30 seconds or less. Long waits are marked `>> fast-forward` on screen.

Recovery words, enrollment codes, tokens and fingerprints in the videos belong to this disposable demo. They are not from a live office.

Published on the [Demos page](https://itcmdr.weirdbrains.com/demos.html).
