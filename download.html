Builds are unsigned for now

The Windows installers and the macOS app aren't code-signed yet. Windows SmartScreen will warn about them, and machines where SmartScreen or app control is locked down won't install them at all. On macOS, Gatekeeper may block the app until you allow it. Signed builds are coming. Check each file against SHA256SUMS before you install it.
