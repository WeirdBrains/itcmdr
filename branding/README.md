# itcmdr brand icon set

Concept: navy shield (#0B2350→#0E3473) with teal (#2EE6E0→#22D3D3) terminal prompt.
- office: light (#F3F2F2) rounded tile, navy shield, teal prompt.
- admin: inverted — navy tile, white shield, navy prompt. Mono admin = outlined shield (office mono = solid shield with prompt cut out).
Regenerate everything with: python3 build.py (needs cairosvg + Pillow, Inter font).

Android adaptive layers are 108dp canvases with the shield inside the 66dp safe circle (scale 0.70). iOS 1024 + appiconset PNGs are opaque RGB, full-bleed square. Web maskable icons use scale 0.66.
